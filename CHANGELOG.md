# Changelog

## 0.1.1 — 2026-11-01

CLI `network address` теперь показывает сохранённый результат внешней проверки,
как и TUI. При работающем relay копирование адреса не запрашивает лишний public-IP сервис.

## 0.1.0 — 2026-11-01

Первый рабочий релиз: мастер установки, Python CLI/Textual TUI, user systemd service,
приватная консоль, backup/restore, официальные источники ядер, Modrinth/CurseForge,
темы и опциональный публичный TCP relay.

Реальный smoke test: Paper 26.3 + Java 25, публичное подключение клиента 1.21.11
через ViaBackwards, подтверждённая регистрация AuthMe и удаление тестового аккаунта.

Поддержка отдельных ядер не означает live-проверку каждого из них.
Ограничения и проверенное поведение подробно описаны в README и docs/VALIDATION.md.
