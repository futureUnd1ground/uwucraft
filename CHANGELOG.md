# Changelog

## 0.7.3 — 2026-11-02

- Stop/restart останавливает фактическую JVM даже при failed/inactive systemd unit и отдельном supervisor. Ожидание завершения процесса и освобождения runner lock; повторный Start не создаёт второй supervisor, перед запуском сбрасывается systemd start-limit.
- Общий lifecycle backend для CLI/TUI и мастера создания. Сериализация управления и защита запуска от одновременной установки файлов. Живой PID имеет приоритет над устаревшей меткой Stopped; ошибки проверки процесса дают Unknown, а не разрешение на изменение мира.
- В окне установки файлов — живой статус JVM и «Остановить сервер»; установка разрешается после её завершения. CLI печатает результат операции.

## 0.7.2 — 2026-11-02

- Linux owner shortcut: при игре на серверном ПК прежний публичный адрес ведёт напрямую в JVM без обхода через relay/VPN. Узкое nftables output NAT-правило ограничено UID, публичным IPv4 и портом. Путь внешних игроков не меняется.
- `network owner-route enable|disable|status`, кнопка «Быстро с этого ПК» в Network и явная отметка в debug. Root-owned helper/timer отслеживает смену relay-адреса, удаляет правило при невалидном состоянии/PID и восстанавливает после сброса nftables.

## 0.7.1 — 2026-11-02

- Physical relay: неблокирующая двусторонняя передача с ограниченными буферами и backpressure. Загрузка чанков больше не блокирует обратные пакеты при заполнении TCP-окна; убран 10-секундный таймаут блокирующей отправки. TCP_NODELAY включён с обеих сторон моста.
- Регрессионная проверка передачи keepalive при остановившемся получателе большого потока, сохранена проверка half-close.

## 0.7.0 — 2026-11-02

- Предварительная проверка модов при пакетной установке и перед JVM: зависимости, версии Minecraft, дубли mod ID, client-only Fabric и объявленные конфликты; учёт вложенных JAR, без подмены resolver загрузчика.
- `mods-check`, структурированный `debug --client-dir --external --output` и окно диагностики TUI с копированием отчёта и ограниченным чтением журналов.
- Транспорт relay physical/auto/system: loopback TCP bridge с привязкой исходящих сокетов к обычному адаптеру, без изменения общих маршрутов и выключения VPN. Linux — узкое постоянное nftables egress-исключение с root-owned helper; ограничения WFP Windows сообщаются явно.
- SHA-256 кэш bore позволяет запускать проверенный binary без запроса GitHub при каждом старте. Фиксирован INFO-уровень логирования для получения выделенного relay-порта.

## 0.6.0 — 2026-11-02

- Единое окно Drag & Drop в Mods/Plugins/Packs/Worlds: несколько путей, многострочная вставка, file URI, Linux/Windows quotes, предпросмотр и общий backend с CLI `add-files --trust-files`.
- Определение локальных модов/плагинов, datapack/resourcepack, MRPACK, ZIP server pack и миров по содержимому; проверка ядра и клиентских Fabric-модов.
- Пакетная подготовка файлов, отказ от перезаписи, откат новых файлов при ошибке, SHA-256 реестр и защита изменённых конфигов при удалении.
- Тесты реальной TUI-вставки/кнопки и установки нескольких файлов добавлены в Linux и Windows CI.

## 0.5.2 — 2026-11-02

- `network configure` автоматически перезапускает relay без действующего состояния, включая процесс с удалёнными файлами после пересоздания сервера. Minecraft и мир не перезапускаются.
- Зависшее установление соединения bore ограничено 20 секундами, затем выполняется повторная попытка; недоступный старый remote-порт сбрасывается автоматически.
- Для Windows перед повторным запуском relay без состояния останавливается старая задача Планировщика.

## 0.5.1 — 2026-11-01

- TCP relay bore.pub стал стандартным способом публичного доступа для новых серверов CLI/TUI, включая Windows. Входящий firewall и NAT в этом режиме не изменяются.
- `create --public-access direct` сохраняет прямую публикацию; `network configure --public-access relay|direct` переключает существующий профиль.
- Общий сетевой backend подтверждает адрес только независимой проверкой своего Minecraft-сервера; сбой relay не подменяется адресом выхода VPN. Существующие профили и миры автоматически не меняются.

## 0.5.0 — 2026-11-01

- Явно включаемый TCP relay bore.pub для CGNAT: общий backend CLI/TUI, SHA-256 официального клиента, Linux systemd и Windows Task Scheduler, переподключение и внешняя проверка каждые 3 минуты.
- Адрес для игроков и буфер обмена требуют свежей внешней проверки именно своего сервера; VPN exit, чужой сервер, остановленный relay и устаревший результат больше не выдаются за рабочее приглашение.
- Диагностика фактического маршрута VPN и WAN CGNAT.
- Сохранены доработки установленной версии: импорт существующих серверов без перемещения мира, управление профилями, системный запрос повышения прав и устойчивые загрузки Java.

## 0.4.0 — 2026-11-01

- Несколько независимых серверов: CLI --profile, profile list/use, TUI переключатель, отдельные миры/Java/порты/units/tasks и безопасный default legacy профиль.
- Официальный каталог версий CLI/TUI, автоматический незанятый порт, Java 8 fallback для старых Mojang manifests, legacy Forge launcher и общая версия NeoForge prefix mapping.
- Совместимость Java-клиентов: ViaVersion/ViaBackwards, опциональный ViaRewind, backup и управляемый restart, SHA-256 и staged plugin install.
- Windows ZIP содержит официальный подписанный установщик Python; установка без winget, с проверкой SHA-256 и PSF Authenticode. Git checkout скачивает тот же файл автоматически.
- Backup/restore default сохраняет другие профили; старые фоновые units фиксируются на default без перезапуска мира.

## 0.3.0 — 2026-11-01

- Нативный Windows backend: APPDATA/LOCALAPPDATA, Windows file locks и защищённая локальная named-pipe консоль.
- Автоустановка Temurin ZIP с java.exe и Forge/NeoForge win_args.txt; единый мастер CLI/TUI сохранён.
- Defender Firewall через одноразовое UAC, маршруты через PowerShell, буфер Windows, UPnP/NAT-PMP без изменения общего протокольного backend.
- Пользовательский Task Scheduler после входа, watchdog crash/restart, явный stop, ежедневные backups и отдельное продление проброса.
- install.cmd/install.ps1, ярлык и пользовательский PATH; Windows CI с настоящим JVM lifecycle и Java download.
- UTF-8 для конфигураций и журналов на обеих ОС; Linux backend и существующий мир сохранены.

## 0.2.0 — 2026-11-01

- Общий backend создания сервера: CLI `create`, короткие алиасы `auto`/`install` и TUI «Создать сервер».
- Семь необходимых параметров, автоматические defaults и явная EULA; после неё конфигурационных вопросов нет.
- Прямой публичный IPv4, узкое исключение nftables, UPnP/NAT-PMP с продлением аренды, независимый внешний probe и проверка MOTD новой установки.
- Отчёт о правах, CGNAT, автопробросе и доступности без ложного «успеха»; итоговая карточка и копирование только публичного адреса.
- Удалён прежний дополнительный сетевой backend; миграция отключает его сервис, сохраняя сервер и мир.
- Расширены CLI/TUI/protocol tests и добавлена реальная nftables-проверка в изолированном network namespace.
